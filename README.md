# 🏡 House Price Prediction

A Machine Learning project that predicts house prices based on features such as location, area, number of bedrooms, and bathrooms.

## 📌 Project Overview

This project uses Python and Machine Learning to analyze housing data and predict house prices. It includes data cleaning, data visualization, model training, and evaluation.

## 🎯 Objectives

- Analyze housing data.
- Clean and preprocess the dataset.
- Perform Exploratory Data Analysis (EDA).
- Train a Machine Learning regression model.
- Predict house prices.
- Evaluate model performance.

## 🛠️ Technologies Used

## 📊 Model Evaluation

The model can be evaluated using the following metrics:

- **MAE:** Mean Absolute Error
- **MSE:** Mean Squared Error
- **RMSE:** Root Mean Squared Error
- **R² Score:** Measures how well the model explains variations in house prices.

Actual evaluation results can be added after training the model.
